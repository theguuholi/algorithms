# 📚 Algorithms Repository

A comprehensive collection of algorithm implementations in **Java** and **Elixir**, organized for learning and reference.

## 🎯 Project Structure

```
algorithms/
├── docs/                    # Algorithm documentation with explanations
├── java/                    # Java implementations (Java 21)
├── elixir/                  # Elixir implementations (Elixir 1.15+)
└── README.md               # This file
```

## 🚀 Quick Start

### Java

```bash
cd java
mvn test
```

See [Java README](java/README.md) for detailed setup and usage.

### Elixir

```bash
cd elixir
mix test
```

See [Elixir README](elixir/README.md) for detailed setup and usage.

## 🎓 Features

- **Clean Code**: Well-documented implementations with comprehensive comments
- **Test Coverage**: Multiple test cases for each algorithm including edge cases

- **Modern Stack**: Java 21 with Maven, Elixir 1.15+ with Mix
